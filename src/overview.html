Jeu de Jest - Documentation du Projet

Description Générale

Jest est un jeu de cartes stratégique pour 3 à 4 joueurs, implémenté en Java avec une architecture MVC (Model-View-Controller). Le projet propose deux interfaces utilisateur fonctionnant en parallèle : une interface en ligne de commande (CLI) et une interface graphique (GUI).

Architecture du Projet

Structure des Packages

  • main : Point d'entrée de l'application, lance les deux interfaces simultanément
  • controller : Contrôleurs pour l'interface en ligne de commande
  • service : Services de gestion centralisée de la partie
  • model : Modèle métier complet du jeu (règles, entités, logique)
  • view : Interface graphique Swing avec affichage des cartes

Patterns de Conception Utilisés

  • MVC (Model-View-Controller) : Séparation claire entre logique métier, interface et contrôle
  • Strategy : Pour les différentes stratégies de jeu (humain, robot aléatoire)
  • Visitor : Pour le calcul des scores et l'attribution des trophées
  • DTO (Data Transfer Object) : Pour la sérialisation et la sauvegarde
  • Singleton-like : GameManager centralise l'accès à la partie courante

Fonctionnalités Principales

Modes de Jeu

  • Règles de base : Gestion classique des cartes cœur avec joker
  • Variante : Valeur double des cœurs selon certaines conditions
  • Extension Miroir : Carte spéciale qui copie la meilleure carte du joueur

Types de Joueurs

  • Humain : Choix interactifs via CLI ou GUI
  • Robot aléatoire : Décisions automatiques aléatoires

Système de Sauvegarde

  • Sauvegarde complète de l'état de la partie (joueurs, cartes, scores, manches)
  • Chargement de parties sauvegardées
  • Sérialisation via objets DTO

Utilisation

Compilation

javac -d bin -sourcepath src src/main/*.java src/controller/*.java src/service/*.java src/model/*.java src/view/*.java

Exécution

java -cp bin main.Main
